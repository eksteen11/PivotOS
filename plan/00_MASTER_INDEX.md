## The product in one paragraph

Pivot OS is DJ Eksteen's Founder Operating System. Everything he receives is captured, AI classifies and prepares it, he approves what matters, AI executes what is safe, and every step leaves an audit trail. It is not a CRM, not an ERP, not a task manager, and not a company-wide staff tool. Clark is the shared finance product. The Digikraal marketplace is a separate platform. Pivot connects them and protects the founder's judgement.

---

## The chain that defines everything

```
capture → inbox item → classification → conversion proposal
       → approval (if risky) → execution → audit → memory → learning
```

Any feature that bypasses this chain does not belong in Pivot OS.
